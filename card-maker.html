📄 Card HTML

📲 Kaise use karein

  1. Upar 3 fields bharo → Generate dabao
  2. Download .html dabao (file save ho jayegi)
  3. Is HTML file ko host karo — koi bhi free static host (Netlify Drop, tiiny.host, ya apna blog/server)
  4. Us hosted page ka URL X par tweet karo (image upload mat karo!)
  5. X image card dikhayega → click par destination link khulega ✅
⚠️ Zaroori: X card ko cache karta hai. Agar pehli bar card na dikhe to hosted URL ke aakhir me ?v=2 laga kar dobara tweet karo. Test karne ke liye X ka Card Validator use karo.
